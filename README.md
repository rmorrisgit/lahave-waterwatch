# LaHave WaterWatch

**Independent Development Prototype**

An interactive water-quality monitoring dashboard exploring nearly 20 years of environmental data from the LaHave River watershed in Nova Scotia, Canada.

Originally developed as a personal project in preparation for a hackathon, LaHave WaterWatch serves as a prototype for exploring environmental data processing, visualization, and interactive analysis.

### Live Demo

**[Launch LaHave WaterWatch](https://lahave-waterwatch.rf-morris.workers.dev/)**

### Features

- Interactive watershed map featuring 20 historical monitoring locations
- Water-quality trends, station comparisons, and seasonal analysis
- Exploratory environmental health rankings and indicators
- Approximately 56,000 measurements across 48 water-quality indicators
- Historical monitoring data from 2007 to February 2026
- Data-quality indicators and identification of unusual readings and potential guideline exceedances

### Prototype Disclaimer

LaHave WaterWatch is an independent development prototype intended for educational, exploratory, and demonstration purposes.

The application uses historical monitoring data rather than real-time measurements. Environmental health rankings, calculated indices, and flagged readings are experimental interpretations and should not be treated as official environmental assessments.

This project is not an official Coastal Action or DataStream monitoring service and is not intended for regulatory decisions, public-health assessments, or determining water safety.
